# Build Decisions Log

Ambiguities resolved during the V0 build, per the brief's working style: when in
doubt, choose the interpretation consistent with the product thesis
(honesty > flattery).

## Environment & stack

- **Python 3.11 venv** (not the system 3.14): the full scientific stack
  (pandas/numpy/pyarrow/matplotlib) has mature wheels for 3.11; the brief
  requires 3.11+. Homebrew `python3.11` is present on this machine and pinned
  in `Makefile`/`dev.sh`.
- **Next.js 15 / React 19** (brief said "Next.js 14"): 15 is the current stable
  App Router release; nothing in the brief depends on 14-specific behavior.
- **Charts are hand-rolled SVG** (no charting dependency): the Truth Report
  needs log-scale equity with a shaded OOS region, a visually-subordinate gross
  line, an underwater plot, and a regime timeline — all with text/table
  fallbacks (Gap #12). Owning the SVG keeps every one of those requirements
  first-class instead of fighting a library.
- **Migrations are plain SQL files** applied in order and tracked in a
  `schema_migrations` table (no Alembic). Transparent, testable, adequate for a
  single-user SQLite file; SQLAlchemy models mirror the DDL so the V1 Postgres
  swap stays mechanical.

## Engine semantics

- **Trading calendar = SPY's own index** (Gap #6 explicitly allows this instead
  of `exchange_calendars`): every run's calendar is the set of days SPY traded.
  Day-count conventions live in ONE table (`backend/dsl/conventions.py`) that
  the engine, the LLM system prompt, and the glossary all render from.
- **Stop-loss / take-profit are cut from the V0 DSL** (Gap #1, per the build
  prompt): stops on daily bars need fill-rule semantics (gap-through handling)
  the engine can't honestly provide with close-only data. The validator rejects
  them with a plain explanation. `hold_days` is defined precisely instead:
  **overlapping cohorts, equal capital per active cohort** — each rebalance day
  starts a new cohort that lives `hold_days` trading days; the portfolio splits
  capital equally across active cohorts; within a cohort, the spec's weighting
  rule applies. A golden fixture proves the semantics by hand.
- **Cost formula is Section 3's, verbatim**: `turnover[t] = 0.5 * Σ|w[t] −
  w_drifted[t−1]|`, `net[t] = gross[t] − turnover[t] × bps/10⁴`, applied on the
  execution day. Turnover is measured against drifted (not stale) weights.
- **Deterministic tie-breaking** (Gap #2): ranking sorts by (score, then ticker
  alphabetically). Identical inputs produce identical selections on every
  platform.
- **Risk-free rate**: try 13-week T-bill (^IRX) from the data layer; on any
  failure fall back to 0 **with a disclosed audit NOTE** — never silently.

## Data

- **Fixture panels double as offline data**: the frozen War-list and S&P 500
  CSVs from the original session are checked into `fixtures/` and seeded into
  the parquet cache by `make seed`, so the app (and the selection-bias audit's
  neutral-universe re-run) works with zero network access.
- **S&P 500 constituent seed list**: checked in at
  `fixtures/sp500_constituents.csv`, sourced from the Wikipedia "List of S&P
  500 companies" table (snapshot taken June 2025 during the original session).
  `scripts/refresh_sp500.py` re-scrapes it on demand; the audit layer always
  discloses that a *current* constituent list is still mildly survivorship
  biased ("less biased, not unbiased").
- **Snapshot format is parquet** with a SHA-256 content hash stored on the Run
  row. Re-runs replay the snapshot by default; "refresh data" is the only path
  to new numbers.

## LLM layer

- **Model: `claude-sonnet-5`** (env-overridable via `HONEST_LLM_MODEL`). The
  brief's Section 2 suggested Opus-class; the build prompt (which wins)
  specifies the current Sonnet-class model. The eval harness is the instrument
  for judging whether a model change is safe.
- **The readback shown on the spec card is generated by Python template code
  from the validated JSON** — never by the LLM call that produced the spec
  (non-negotiable #6). The LLM's own readback, if any, is discarded.
- **Translation cache**: SQLite keyed by (prompt version, SHA-256 of input
  text). Cache hits skip the API entirely; every translation attempt is logged
  and doubles as the future eval corpus (Gap #11).

## Reports & export

- **PNG/PDF export is rendered server-side with matplotlib**, so the
  disclaimer is drawn into the artifact pixels (and embedded in PNG metadata),
  not overlaid by the browser. A shared image detached from the app still
  carries the legal footer (Gap #10).
- **Verdict always uses the pessimistic cell**: net-of-costs, validation
  segment. Green requires beating SPY at 20 bps net in the holdout, with no
  FATAL findings and regime coverage including a bear market.

## Dip-buy cost-collapse reproduction (Definition of Done)

The original session's "gross win → net death" came from `reversal.py`, which
holds **today's losers for one day** (full daily portfolio replacement) and
subtracts a flat daily cost. The brief's worked example #2 holds for 5 days
(overlapping cohorts), which mechanically trades ~1/5 of the book per day, so
turnover-scaled costs bite ~5× less. Both variants are golden-tested; the
Definition-of-Done check ("flips from beating SPY gross to losing at 20 bps")
is asserted against the empirical result on the frozen fixture panel and
reported honestly either way.
